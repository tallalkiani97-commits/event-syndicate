# The Event Syndicate

**Premium editorial landing-page concept for curated events and brand experiences.**

The Event Syndicate explores how a small static website can create a strong identity for weddings, brand launches and private events. The design uses typography, spacing and a focused call to action rather than a heavy framework.

## Experience goals

- Make the brand statement immediate.
- Keep the page visually premium on mobile and desktop.
- Give visitors a clear enquiry action.
- Keep the code easy to customize for a real event business.

## Features

- Responsive hero composition.
- Event category labels.
- Premium dark-and-gold visual system.
- Lightweight enquiry interaction.
- No build step required.

## Quick start

Open `index.html` directly, or serve it with:

```bash
python3 -m http.server 8000
```
